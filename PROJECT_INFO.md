## 📝 Customization Needed

### 1. Update Contact Information
Edit these files:
- `src/components/Hero.js` - WhatsApp link (line 21)
- `src/components/Contact.js` - Email, phone, location
- `src/components/Footer.js` - All contact details

### 2. Update Pricing
Edit `src/components/Pricing.js` to adjust:
- Plan prices
- Features included
- Plan descriptions

### 3. Update Company Name
Search and replace "LaunchTech" with your company name in:
- `src/components/Navbar.js`
- `src/components/Footer.js`
- `src/app/layout.js` (SEO title)

### 4. Add Your Logo
Replace text logo in `src/components/Navbar.js` with an image:
```javascript
<Image src="/logo.png" alt="Logo" width={150} height={40} />
```
